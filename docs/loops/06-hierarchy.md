# Loop 06 — Hierarchy

Make the work the page. Headlines must not push the board or the report below the fold.

## Prompt

```
Drain LedgerLane page heads for Board and Reports.

Rules from docs/STYLE_GUIDE.md:
- Signed-in work pages use Title role (1.5rem / 24px), not Display.
- Eyebrow + short title. No manifesto line on signed-in pages. Keep “WORK, ACCOUNTED FOR.” on auth only.
- At 900×700 the first kanban cards and the report sheet must be visible without scrolling past decoration.
- One primary action per view (New task is acid). Do not add a second poster.

Do not remove New project, More actions, filters, or People.
Verify at 900×700 and 1440×900. Then stop; do not start loop 07.
```

## Verify

- Board heading is a compact `.page-title` (not a 70px poster).
- Reports heading is a compact `.page-title`.
- Auth art may stay loud.
- Waiting may keep a Display heading because it *is* the page.
